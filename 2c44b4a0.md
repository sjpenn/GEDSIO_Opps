## 💡 How The System Works

```
UPLOAD RFP DOCUMENTS
        ↓
PROMPT 1: CLASSIFY (SINGLE or MULTI-DOCUMENT?)
        ↓
    ┌───┴───┐
    │       │
    ▼       ▼
SINGLE   MULTI
    │       │
    │       ├─→ Map to sections
    ├─→ PROMPT 2: Detect sections (A-M)
    │
    ▼
EXTRACT TEXT → STORE IN DB
    ↓
PROMPT 3: Extract requirements from sections
    ↓
PROMPT 4: Map evaluation criteria to requirements
    ↓
PROMPT 5: Generate executive summaries
    ↓
PROMPT 6: Format for UI display
    ↓
BUILD REACT UI
    ├─ Document list
    ├─ Clickable items
    └─ Slideout panel with formatted content
    ↓
BUSINESS TEAM USES FOR PROPOSAL DEVELOPMENT
```
