## System In 60 Seconds

**Problem:** Government RFPs come in different formats (single or multi-document). Need to classify them, extract sections, parse requirements, and display in UI.

**Solution:** 
- **Prompt 1** → Classify document type (SINGLE vs MULTI)
- **Prompt 2** → Detect section boundaries if single document
- **Prompt 3** → Extract requirements from sections
- **Prompt 4** → Map evaluation criteria to requirements  
- **Prompt 5** → Generate summaries
- **Prompt 6** → Format for UI display
- **Prompt 7** → Batch process multiple opportunities

**UI:** Click document name → slideout panel shows formatted content + summary

## The 7 Production Prompts

All ready to copy-paste into Claude or GPT-4. No customization needed.

| Prompt | Purpose | Input | Output | Time |
|--------|---------|-------|--------|------|
| **1** | Document Classification | Filename list | SINGLE/MULTI type + strategy | 30 sec |
| **2** | Section Detection | Full text (single doc) | Section A-M boundaries | 1-2 min |
| **3** | Requirement Extraction | Section text | Structured requirements | 2-3 min |

## System Architecture

```
Upload RFP
    ↓
Classify (Prompt 1)
    ├─ SINGLE? → Detect sections (Prompt 2)
    └─ MULTI? → Map to sections directly
    ↓
Extract Text → Store in DB
    ↓
Parse Sections (Prompts 2-3)
    ├─ Identify boundaries
    └─ Extract requirements
    ↓
Analyze (Prompts 4-5)
    ├─ Map to evaluation criteria
    └─ Generate summaries
    ↓
Display (Prompt 6 + React)
    ├─ Document list
    ├─ Click → Slideout
    └─ Show summary + content
    ↓
Business team uses for proposal
```

---

## Database Tables

```
opportunities (id, notice_id, title, classification_type)
    ├─ documents (id, filename, extracted_text)
    │   ├─ sections (id, section_letter, content)
    │   └─ section_summaries (id, summary_text)
    │
    └─ requirements (id, requirement_text, category)
        └─ evaluation_mappings (id, evaluation_factor, weight)
```

## What Each Prompt Does

### Prompt 1: Classification
**Input:** List of filenames
**Output:** 
```json
{
  "classification": "SINGLE_DOCUMENT",
  "confidence": "HIGH",
  "extraction_strategy": "Detect sections A-M within document"
}
```

### Prompt 2: Section Detection
**Input:** Full document text
**Output:**
```json
{
  "sections": [
    {"letter": "A", "start_line": 5, "end_line": 50},
    {"letter": "C", "start_line": 51, "end_line": 400},
    {"letter": "M", "start_line": 401, "end_line": 500}
  ]
}
```

### Prompt 3: Requirement Extraction
**Input:** Section C text
**Output:**
```json
{
  "requirements": [
    {"id": "C_001", "text": "Provide 24/7 support", "category": "SERVICE"},
    {"id": "C_002", "text": "Response time <2 hours", "category": "PERFORMANCE"}
  ]
}
```

### Prompt 4: Evaluation Mapping
**Input:** Sections M + C
**Output:**
```json
{
  "mapping": [
    {
      "evaluation_factor": "Technical Approach (40%)",
      "related_requirements": ["C_001", "C_002", "C_005"],
      "win_strategy": "Show deep understanding and innovative approach"
    }
  ]
}
```

### Prompt 5: Executive Summary
**Input:** Any section
**Output:**
```json
{
  "summary": "Proposal must include 24/7 support with <2hr response times",
  "proposal_approach": "Describe support team structure and escalation process",
  "red_flags": ["Response time is critical metric for scoring"]
}
```
